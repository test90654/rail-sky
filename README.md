# 休日の撮影空模様（鉄道撮影向け）

日立・いわきの木曜・金曜について、気象庁モデル（Open-Meteo経由）の低・中・上層雲量と降水量から、
日中の時間ごとに「晴れ／晴れ間／薄日・曇り／曇天／雨」を判定します。

- **ダッシュボード**：`index.html`。開くたびにブラウザが最新予報を取得します（サーバー不要）。
- **通知**：GitHub Actions が毎日 20:47 に `notify.py` を実行し、スマホの ntfy アプリへプッシュ（メールも任意）。

## セットアップ（15分ほど）

1. GitHub で新しいリポジトリ（Public 推奨）を作り、このフォルダの中身をすべてアップロード
   （`.github/workflows/notify.yml` を含む）。
2. **ダッシュボード公開**：Settings → Pages → Branch を `main` / `/(root)` にして Save。
   数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で見られます。
   その URL を `config.json` の `dashboard_url` に入れると、通知タップでダッシュボードが開きます。
3. **スマホ通知**：ntfy アプリ（iOS / Android）を入れ、他人と被らないトピック名
   （例 `railsky-` ＋ランダムな英数字）を購読。
   リポジトリの Settings → Secrets and variables → Actions で `NTFY_TOPIC` にその名前を登録。
4. （任意）メールも欲しい場合は `MAIL_TO`、`SMTP_USER`（Gmailアドレス）、`SMTP_PASS`（Gmailのアプリパスワード）を登録。
5. Actions タブ → rail-sky-notify → Run workflow で試し送信。

## 調整

- 休みの曜日：`config.json` の `weekdays`（0=日 … 4=木 5=金 6=土）。
- 地点の追加・変更：`locations` に名前と緯度経度を追加（例：十王、小木津、勿来など撮影地の座標）。
  ダッシュボードは `config.json` を読むので、両方に自動で反映されます。
- 通知時刻：`notify.yml` の cron（UTC表記。JST−9時間）。

## 判定の考え方

- 実効雲量＝低層雲をそのまま、中層雲を7割、上層雲（巻雲）を3割の重みで合成。
  30%未満=晴れ、60%未満=晴れ間、85%未満=薄日・曇り、それ以上=曇天。降水0.1mm以上=小雨、0.5mm以上=雨。
- 1日の判定は日の出〜日の入りの時間で：晴れ5時間相当以上=◎、2時間以上=○、雨3時間以上=✕、それ以外=△。
- 3日先まではMSM（5km）で比較的確度が高く、それ以降はGSMで目安です。最終確認はSCWで。

## 狙いの列車（E501系）の時刻

- `trains.json` に、E501系が入るとされる普通列車10本（上り 526M・528M・558M・562M・568M／下り 531M・533M・559M・567M・571M。運用A101・A102）の全停車駅の時刻を入れています。
  時刻はJR東日本「駅の時刻表」2026年10月版から取得したものです。平日も土休日も同じ時刻です。
- どの列車にE501系が入るかは、勝田車両センターE501系基本編成の運用表（2026年3月、全日）によります。E531系が代わりに走る日もあります。
- ダッシュボードには、駅を切り替えられる上下線の時刻表を表示します。各休日の天気の帯には、列車が通る時間に ● を付けます。
  通知には「↑07:30晴れ ↓08:11薄日」のように、列車ごとの空模様が入ります。
- 撮影地を基準にする駅は `watch_stations` で変えられます（例：`"hitachi": "小木津"`）。
- ダイヤ改正（例年3月）や運用の変更があったら、`trains.json` を更新してください。

## ダイヤグラム

- 時刻表の「ダイヤグラム」タブで、E501系が走る時間帯（朝 5:50–10:00、午後〜夜 15:00–22:40）の水戸〜草野間のダイヤグラムを表示します。
- 線の色分け：E501系＝太い青、特急（ひたち・ときわ）＝オレンジ、普通（E531系など）＝灰色。臨時列車は点線です。
- データは `diagram.json` に入っています（JR東日本 駅の時刻表 2026年10月版・平日）。特急の通過駅は時刻がないので、停車駅の間を直線で結んでいます。貨物列車と回送列車は入っていません。
